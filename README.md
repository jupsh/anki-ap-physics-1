# AP Physics 1 for Anki

An Anki deck covering the AP Physics 1 course. It follows the College Board course framework
(the structure Khan Academy's AP Physics 1 course uses): 8 units, 43 topics, 415 notes.

**[Download AP_Physics_1.apkg](https://github.com/jupsh/anki-ap-physics-1/releases/latest/download/AP_Physics_1.apkg)**,
then in Anki choose **File → Import**.

## What's in it

- **Decks:** `AP Physics 1 › Unit N · Title › N.M Topic`
- **Tags:** `AP_Physics_1::U<N>_<Unit>::<N.M>_<Topic>`, plus `formula`, `problem`, `diagram`
- **Note types:** `AP Physics 1 · Basic` (front/back, an optional diagram on either side, extra
  notes) and `AP Physics 1 · Cloze` (diagram on the back only)
- **Math:** MathJax (`\( \)` / `\[ \]`)
- **Diagrams:** SVGs generated by `ap_physics_1/diagrams.py`, inverted automatically in night
  mode. Colours: forces red, velocity blue, acceleration green, displacement purple,
  momentum/rotation orange.

## Building it yourself

Needs [uv](https://docs.astral.sh/uv/).

```sh
uv run python ap_physics_1/build.py                 # writes dist/AP_Physics_1.apkg
uv run python ap_physics_1/build.py --html out.html # plus an HTML preview of every card
```

Cards live in `ap_physics_1/content/u1.py` … `u8.py`. Note GUIDs come from the section and the
card text, so re-importing after an edit updates unchanged cards but adds an edited card as a new
note.

Corrections are welcome: open an issue or a pull request.
